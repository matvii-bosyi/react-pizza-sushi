# 🍕🍣 Pizza Sushi Project

Educational project built with **React + TypeScript**, implementing a client-side app for a pizza & sushi delivery service.  
The project is focused on practicing API integration, authentication, state management, and modern frontend libraries.

---

## 🚀 Features
- 🔑 **Authentication**
  - JWT tokens
  - OTP (phone verification with code)
  - OAuth login
- 📦 **Products**
  - Product listing
  - Favorites
- 🛒 **Cart**
  - Add / remove products
  - Manage cart state
- 🏬 **Restaurants**
  - Display list of restaurants
  - Favorites

---

## 🛠 Tech Stack
- ⚛️ React (with TypeScript)
- 🎨 TailwindCSS
- 📝 React Hook Form + Zod
- 🔄 TanStack Query
- 📦 Zustand
- 🔗 Backend: custom API (already provided)

---

## 🖥️ Getting Started

Clone the repo and install dependencies with [Bun](https://bun.sh):

```bash
git clone https://github.com/your-username/ReactPizzaSushi.git
cd ReactPizzaSushi
bun install
bun run start
```
